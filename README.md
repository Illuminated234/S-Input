# S-Input
This application intercepts controller input events and maps them to simulated keyboard keystrokes in real time!
Users can configure custom bindings that associate controller buttons, triggers, and analog stick movements with specific keyboard keys or key combinations. The system enables seamless interaction between controller hardware and software that natively accepts only keyboard input. 
The software increases compatibility between input devices and applications by removing *some* limitations. It provides a flexible input layer that can adapt controllers to virtually any keyboard-driven program, making it valuable for gaming, accessibility solutions, automation tasks, and custom user interfaces.
